# 화석 탐구실

> 생물의 몸과 흔적은 어떻게 지층에 기록될까?

2022 개정 교육과정 고등학교 통합과학2 '지질시대 및 화석' 단원을 위한 **화석 탐구 웹 학습 자료**입니다.
설치 없이 브라우저에서 바로 열리며, 태블릿·전자칠판 등 수업 환경에 맞춰 화면이 조정됩니다.

## 바로 보기

https://fossil-lab.vercel.app

웹 브라우저에서 주소로 바로 이용합니다. 설치, 회원가입, 로그인이 필요하지 않습니다.

## 구성

| 탭 | 주제 | 활동 |
| --- | --- | --- |
| 1 | 화석 형성 과정 | 죽음 → 매몰 → 광물 충전·치환 → 융기 → 풍화·침식 → 노출·발견까지 단계별 애니메이션으로 따라가기 |
| 2 | 화석으로 잘 남으려면? | 생물(해파리·고사리·조개·공룡), 매몰 속도, 분해 속도를 골라 결과를 비교하는 가상 실험 |
| 3 | 몰드·캐스트 | 붕어빵 틀에 빗대어 몰드(빈 공간)와 캐스트(채워진 모양)의 차이를 익히고, 암모나이트 화석으로 확인하기 |
| 4 | 생흔 화석 | 진흙 위를 드래그해 발자국을 남기거나 굴을 파 보고, 그 흔적이 화석이 되는 과정을 단면으로 관찰하기 |
| 5 | 핵심 퀴즈 | 화석화 조건, 몰드·캐스트, 인상 화석, 생흔 화석을 확인하는 문제 풀이 |

## 특징

- **단일 파일**: HTML·CSS·JavaScript가 모두 `index.html` 안에 들어 있습니다. 화면 글꼴만 Google Fonts에서 불러옵니다.
- **직접 조작**: 조건을 바꾸고 화면을 만져 보며 결과를 스스로 확인하는 탐구 중심 구성입니다.
- **반응형**: 태블릿과 휴대폰 화면에서도 그림이 가려지지 않도록 자막과 버튼 배치가 바뀝니다.
- **SVG·Canvas 애니메이션**: 이미지 파일 없이 코드로 그려 화면 크기와 관계없이 선명합니다.

## 수업에서 쓸 때

1. 탭 1로 화석이 만들어지는 전체 흐름을 함께 봅니다.
2. 탭 2에서 조건을 바꿔 가며 "왜 어떤 생물은 화석으로 남기 어려울까?"를 이야기합니다.
3. 탭 3·4로 몰드·캐스트와 생흔 화석의 개념을 구체적인 경험과 연결합니다.
4. 탭 5 퀴즈로 배운 내용을 정리합니다.

> 화면 속 과정은 실제 자연의 화석화 과정을 수업용으로 단순화한 모형입니다.

## 이용 조건
